# Movie Works Images

Upload your movie project images here.

## Format Guidelines:
- **Recommended size**: 400x300px or similar aspect ratio
- **Format**: JPG, PNG, or WebP
- **Naming convention**: Use descriptive names (e.g., `movie-title-1.jpg`, `project-name-poster.png`)

## Instructions:
1. Delete this README.md file
2. Upload your actual movie work images
3. Update the `movieImages` array in `Portfolio.tsx` with the correct image paths

Example path: `/images/portfolio/movies/your-image.jpg`
