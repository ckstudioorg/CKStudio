# CK Studio Image Structure

Use the root-level `DESIGNER_IMAGE_REQUIREMENTS.md` file as the source of truth for image sizes, formats, names, and delivery folders.

Expected folders:

```text
public/images/
├── branding/
├── hero/
├── about/
├── contact/
├── portfolio/
│   └── works/
├── clients/
└── blog/
```

Keep images optimized for the web, use lowercase hyphenated file names, and prefer `webp` for photos, `svg` for logos, and transparent `png` only when an SVG is not available.
