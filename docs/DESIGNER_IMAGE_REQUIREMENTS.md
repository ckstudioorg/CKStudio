## 2. Brand colours and general rules

### Brand palette

| Colour | Hex | Used for |
| --- | --- | --- |
| White | `#FFFFFF` | Background of the whole website |
| CK Red | `#8B0000` | Headlines, key words, buttons and the logo |
| Black | `#111111` | All other text |
| Gold | `#D4AF37` | Rare, special moments only — never as a main colour |

**Note:** Gold is deliberately rare on the site. Please do not build artwork around gold; red and black on white is the core look.

### General rules for every file

- Lowercase file names with hyphens, no spaces — use the exact names in this brief (e.g. `hero-desktop.mp4`).
- Photos and thumbnails: `webp` preferred, `jpg` accepted. Logos and icons: `svg` preferred, transparent `png` otherwise.
- Keep images under 500 KB each unless stated otherwise (export at good quality — we optimise further).
- Use real CK Studio work, team and production stills. No generic stock photos or generic "AI art".
- No text inside images, except official logos or real poster artwork. The website adds headings and labels itself.
- Everything must look good on a white background.

## 3. Hero video (highest priority)

The first section of the website shows a "screen" that grows to full size as the visitor scrolls. The video inside it does not play by itself — it moves forward and backward with the visitor's scrolling, like flipping through film frames. This is why it must be one smooth, continuous shot.

| | Requirement |
| --- | --- |
| Desktop version | 1920 × 1080 px (landscape), 5–8 seconds |
| Phone version (recommended) | 1080 × 1920 px (vertical), same content reframed for phones |
| Motion | One smooth, continuous shot. No cuts, no fast movement, no flashing. Slow, steady motion looks best when controlled by scrolling. |
| Start and end | Starts on pure white (or fades in from white) and ends by fading back to white, so it blends into the page. |
| Text / logos | None inside the video — the website places the headline "Where AI Meets…" around it. |
| Sound | None (the video is always silent). |
| Format | MP4 (H.264), the highest quality export available. Our side converts it for smooth scroll-control, so do not compress it heavily. |
| Still image | One frame from the video, 1920 × 1080 px, `webp` or `jpg` — shown while the video loads. |
| File names | `hero-desktop.mp4` · `hero-mobile.mp4` · `hero-poster.webp` |

### Content ideas

- A slow camera move through the CK Studio edit suite or set, ending on a monitor.
- A cinema lens turning, with the reflection changing from a real scene into an AI-generated world.
- A single film frame that "develops" from sketch → storyboard → AI pre-look → final graded shot.
- A product or character slowly revealed by moving light.

**Note:** The headline sits above and below the video in red and black, so keep the most important part of the picture in the centre of the frame.
